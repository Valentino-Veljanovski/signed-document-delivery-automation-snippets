# Snippets

These snippets are rewritten public examples from a private signed document delivery automation. They show the shape of the helper logic without exposing original workflow data.

## Files

- `attachment-batching-helper.js`: splits PDF attachments into smaller delivery batches.
- `archive-safety-check.js`: checks whether cleanup can run safely after weekly archiving.

## Notes

The snippets use generic field names and placeholder data. They are not copy-paste exports from the private n8n workflow.
